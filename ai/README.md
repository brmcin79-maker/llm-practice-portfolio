## The short version

Daniel is a local program first. The model is optional pattern-sense. It is not a second Daniel. It does not browse his files. It does not write the ledger. It does not run the sitting.

**AI is almost never required.** Ledgers, stay-with, menus, Atlas, HELP topics, ingest, Snapshot, and the next move on a stuck task all work with AI off. That is the floor: AI off still moves.

**AI is required only when you asked for a model job** — free chat body, quiet help before a stay-talk take, a labeled rewrite such as Explain more / AI HELP, or Hybrid paint after a local take. If those are off, he still works.

**Consent is nested.** Connecting a chat path is one door. Quiet help is a smaller door on top of that. Live web is a third door. Paid models are a fourth. Sitting policy (Ask me first / Stay with me / Keep us moving) cannot turn any of those on.

**Data is local.** Long text and old talks live in files and the spine. Each model pulse gets only a small pack local built for that turn. The model window is not memory. Fitting a window is not reading.

## Three modes on the banner

The banner is supposed to say what is actually on. If it says AI is on, chat must work. If chat is off, it should say chat is off. Quiet help has its own on/off word.

| Banner word | Plain meaning | Default |
|-------------|---------------|---------|
| Local logic (DET) | Built-in rules and files. Works with no model. | On |
| AI chat | Optional outside language models (Hybrid / one adapter / Ollama / free cloud). | Off until you connect a path |
| Live web (NET) | Optional search/fetch of the public web. | Off until WEB CONSENT |
| Quiet help | A smaller switch. A model may help Daniel hear a stay-talk line before he answers. | Off. Needs a live chat path. Flow cannot turn it on. |

NET on the banner means consented live web, not “the PC is online.”

People hear one Daniel. They are not supposed to hear “I gave this to the AI.”

## How he works with AI off

This is the product, not a fallback demo.

He can:

- Start, welcome, STATUS, HELP, Atlas, README AUTO, Snapshot
- Create ledgers and tasks, focus, look-at, complete, drop, pause
- Stay with a job: consume-ask, empty → need-list, leftover reprints last take
- Name smaller jobs only after a yes
- Scenario Build as a numbered hub
- Ingest a file or paste into a dossier (store only — the model is not engaged on that write)
- STUDY outline / quiz / critique locally
- Search this sitting and older chronicles
- Local calendar, reminders, time marks (no cron)
- Share / present packs as DET first
- RESOURCE ALIGNMENT, SHOW BOUNDARY, HOW WE WORK

When you stall, local still puts one next method on the table that is still this task. That is pathing. It does not need a model. It must not use live web to decide the next move.

A greeting (`hi`) is local. No model. No task overlay.

One-word command stubs (`set`, `list`, `task`) get a local coach. They do not burn a model call.

**Honest limit:** AI off still moves, but the move is local. He will not sound like a wide knowledgebase. He will not paint a stay-talk take in a warmer voice. Quiet help will not run. Free chat has no model body.

## How he works with AI on

Connecting a chat path does not hand the sitting to the model.

Local still:

- Classifies the line
- Owns the family (`okay` is a nod, not ask-last)
- Chooses the method rung
- Speaks stay-talk
- Fetches any receipt and places a strip in this pulse’s pack
- Wins after the model replies (strip fake ids, unlabeled web, quotes not in a granted strip, kits/rooms not in the named take)

The model may:

- Talk in free chat about **named work in focus**, only over facts local put on the table
- Paint (restate) a stay-talk take after local named it — unless that take is already a complete question, then skip paint
- Fill one quiet-help handle, when that switch is on
- Rewrite locked local facts when you pick a labeled door (Explain more / AI HELP)

The model must not:

- Author menus, banner, Atlas, pulse-0, or numbered doors
- Fire commands
- Browse the house (no tool belt)
- Mint a task from a nod or from chat color
- Invent a lookup when live web is off
- Pretend it read pages it was not given
- Choose JUMP, LENS, or the rung
- Write the people sentence as the product (current design goal, N-03)

Trained world-knowledge is free. Receipts (ledger rows, catalog lines, stored chat, dossier slices, fetched pages) are not. Those must be granted this pulse.

## Consent layers (nested, not one switch)

Each door is its own. Off stays off unless you take that door.

### 1. Connect a chat path — SETUP AI / AI HUB

Off until you connect. Paths include Hybrid (usual try-order Groq → OpenRouter → Gemini → Ollama), a single adapter, Ollama only, or free cloud. Keys live in a local env file on the product machine. Paid OpenAI/Anthropic stay behind ALLOW PAID AI / REVOKE PAID AI.

SETUP AI’s first screen has a numbered quiet-help pick. After any path that leaves a model connected, the same On/Off card is offered. If you pick quiet help with no chat path, he explains and offers SETUP vs Cancel. He does not silent-on.

Flow / HOW WE WORK cannot turn chat on.

### 2. Quiet help — smaller nested consent

People word: quiet help. Not `AI HELP`.

- Off by default
- A chat path must already be connected
- Live web is not used
- You still hear one Daniel
- One silent spend before the stay-talk take
- Local already chose the rung; the model may fill one handle
- Fail → local canonical take
- If the gate drops the slots, SHOW BOUNDARY may say the advise did not land. Not on idle screens. Not slot names

Honest limit: help-on Tries have spent a call that never became slots, or landed slots that did not change the card. Quiet help is wanted. It is not yet a reliable earn.

### 3. Live web — WEB CONSENT / REVOKE WEB

Separate from chat. Local fetches. The model never picks the URL and never uses the net to decide the next move. RESEARCH ADVISE is not live web. Banner NET is this consent, not “online.” Full catch depth is still deferred.

### 4. Paid models — ALLOW PAID AI

A second spend gate on top of a connected path. Free-first is the usual stance until you unlock paid.

### 5. HOW WE WORK — sitting policy, not an AI switch

| People name | What they consented to | Still never |
|-------------|------------------------|-------------|
| Ask me first (default) | Consult before bringing a utility into the path. Does not gate the speaking turn. | Silent writes; flow turning AI or web on |
| Stay with me | Ground + talk; one live offer when stuck | Busybody menus |
| Keep us moving | Local may choose matching utilities already in the catalog | Silent pip, silent self-mod, inventing tasks, the chat model firing commands |

If Hybrid or web are already on, using them is part of the path — do not re-ask every pulse. If they are off, this policy cannot turn them on.

### 6. Writes and spends still wait

A numbered pick, YES after explain, or a typed command that exists. Liking a suggestion set is not a write. Thin speech lets him take the speaking turn. It does not let him spend or write in silence.

### 7. Per-domain AI modes

Some organs (hub, research, persona, enhance, and others) can be off / ask / auto beside the global switch. Ask means confirm before that organ spends. This is extra caution, not a second product.

## Layers of help the model can provide

Think of these as stacked, not as “more AI = smarter Daniel.”

| Layer | When it runs | What it does | What it does not do |
|-------|--------------|--------------|---------------------|
| Floor (no AI) | Always | Ledger, stay-with, menus, pathing, ingest store, Atlas | Sound like a wide knowledgebase |
| Connect path | After SETUP / connect | Makes chat possible | Hand over the sitting |
| Free chat body | Hybrid connected; no command fired; chrome shelved | One default AI body about work in focus | Author numbered doors; mint tasks |
| Stay-talk paint | Hybrid on; local already named a take that is not already a complete question | Restate that named method | Invent rooms, kit, siblings the take did not name |
| Quiet help | Switch on + live path + stay-talk smell | Silent before-take; one handle for the rung local chose | Choose the rung; write the sentence; invent a container |
| Labeled rewrite | Explain more / AI HELP | Optional rewrite of locked local facts | Invent new capabilities |
| RESEARCH ADVISE | You asked; not web | Pattern-sense on granted facts | Fetch the public web |
| Live web | WEB CONSENT + local fetch | Search/fetch with citations | Pathing; silent “know a domain” |
| Paid unlock | ALLOW PAID AI | Paid adapters may be used | Bypass consent or writes |

Menus stay local at every layer.

## When AI is required vs when it is not

**Required (you asked for a model job):**

- You want free chat to answer as a wide language, not as a local card
- You turned quiet help on and stay-talk is pinned
- You picked a labeled AI rewrite
- You asked RESEARCH ADVISE
- You consented to live web and asked a fetch/search

**Not required:**

- Tracking work, staying with a task, getting unstuck on the next method
- Reading Atlas / HELP / Snapshot
- Storing a file or a paste
- Banner, STATUS, numbered hubs
- Greeting, cancel, leave, exit

If a sitting cannot move because the model is down, that sitting used AI as the mouth. That is a design failure under the current goal. Failover (Hybrid switching providers) is for when you already connected chat. It is not the floor.

## How local Daniel works with chunks of data

### What lives locally (no model needed)

- Ledger rows and project headings
- Spine event log (each important turn) plus an index
- Session / pulse count
- Dossiers from INGEST
- Pulse journal and chronicles
- Persona files they confirmed
- Local env keys (never granted to the model as raw secrets in chat dumps)
- Catalog / Atlas truth from the command table

The model never accesses that house on its own. Local smells, searches, disambiguates, and — if several hits could match — asks until you agree. Then it places a **strip** in this pulse’s pack.

```text
Their line
  → Local classifies
      → Unique receipt     → inject into the pack
      → Several or thin    → local asks until they agree (or they leave)
      → Honest miss        → pack says do not pretend
  → Pack this pulse (identity + compact defined words + hot slice + this-turn strip)
  → Model speaks only over that pack
  → Reply is a candidate; local wins
```

No whole-tree dump “just in case.” No forty tools. The model does not choose whether to retrieve.

### With AI off

Chunks still exist. He still writes the spine. He still stores the dossier. STUDY can outline locally. SEARCH is local. SHOW BOUNDARY reads the hot slice. A 10,000-word essay sits in the dossier whether or not a model is connected.

He does not pretend he “read” the whole essay into a chat window. Fitting a window is not reading.

### With AI on

Each pulse gets a **hot slice**, not the whole house:

- Who he is (identity)
- A few defined words in play
- What is in front (focus, last take, in-hand child, quiet-help crumb on the local hold)
- This-turn strip (the one receipt this line needs)

Quiet-help crumbs live on the **local hold**, not in the model window. Re-inject the hot slice every pulse. The window is not memory. Ledger + spine + stored talk are memory.

**Long text.** Ingest is environment. The write does not call the model. When talk later needs the essay, local grants named sections plus a coverage fact: what has been given this sitting, what has not. Map-reduce is local choreography — section by section, then optional one pass over the stitch — not one dump that simulates a close read.

**Old talk.** Unique hit injects silently. Ambiguous: local shows numbered stored talks and asks which one. The model does not interview for memory. After you agree, that strip may enter the pack. The model cannot override the receipt.

**Live web pages.** Local fetches under WEB CONSENT, then may grant a strip. Chat must not invent a lookup when NET is off.

## One sitting, both ways

Same bathroom plan, as an example of the floor vs the optional layers.

**AI off.** You talk through the job. He names Gather supplies and asks what you already have. You say you have none. He asks which listed smaller job the get-list is for. You name an item. He is supposed to use that item next (that last beat is still an open slice). No model call. The ledger and spine still remember.

**Chat connected, quiet help off.** Same local cards. After a statement take, Hybrid may paint that same take in a warmer restatement. Menus stay local. If paint would talk over a complete question, skip paint.

**Quiet help on.** Before the take, one silent call may suggest a handle (for example which listed title). Local type-checks. If it fails, you still get the local card. You still hear one voice. Live web is not used.

If the model is down, the first sitting still works. The second loses paint. The third loses the silent handle. None of them should lose the ledger.

## In one paragraph

Daniel works without AI. The ledger, the next step on a task, and the documents are local. If a model is connected, it may talk about the work in front or quietly suggest one handle — only after those doors are on, and only over the small pack local built for that turn. The model does not run him, does not browse his files, and does not write a task unless there was a yes.

He is not an AI agent. He does not need a model to think. He does not read a whole Drive. Quiet help is not yet reliable every time. Live web is not how he decides the next move.
