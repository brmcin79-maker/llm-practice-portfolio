## 1. What “intelligence” means here

**Law that applies:** **O-01** · **C-02** · **N-03** · **N-01** · **A-02** · **A-09**

Locks (compressed): he is a local work companion, not a chatbot or waiter. Intelligence is **continuity with consent** and **pathing when blocked**. Local decides the beat and speaks. The model is gated pattern-sense on granted facts, not a second Daniel. AI off still moves. Industry-grade is honesty and testability, not “the model is the product.”

Daniel is not a chatbot with a ledger glued on. Law names the mix in two sentences:

- **Continuity with consent.** The ledger and spine remember. Writes and jumps wait for a yes they meant.
- **Pathing when blocked.** When they cannot take the next step, he puts **one method** on the table that still is this task.

Who decides that mix: **local runs the sitting; the model does not**. That is a design bet, not a market proof. It is why a typed line is classified by code before (and often instead of) a model “understanding” it.

Two halves:

| Half | What it is | What it is not |
|------|------------|----------------|
| **Durable / local** | Ledger, spine events, active boundary, numbered menus, stay-with families, method rungs, people copy templates | A second mind. A house model. A knowledgebase of bathrooms |
| **Pattern-sense / model** | Optional. Quiet help (before the take, silent, when on). Hybrid paint (after the take, a restatement). Free chat when stay-with is **not** pinned and chrome is shelved | The mouth on stay-talk. The chooser of JUMP, writes, or the family of the line |

People hear **one voice**. Banner honesty: DET / AI / NET / quiet help (`C-08`). AI off must still move (`N-03`, `A-03`).

**Compare:** Holds. This section is the constitution, not a product bug.

## 2. Broad picture — one typed line

**Law that applies:** **C-03** · **C-05** · **C-06** · **C-08** · **C-12** · **O-03** · **O-07**

Locks: menus and commands are local. Talk and chat are converse. Ordinary talk shelves numbers; FOCUS stays. Digits belong to the printed list. HELP anytime; SHOW MENU reprints this beat. Talk is not gated; writes still wait. Stay-talk (chrome shelved, stay pinned) is local, not free chat. Dumping “just type” as their homework while work is pinned is dropping the ball.

Every pulse is the same outer machine. Inner intelligence only runs if the line is not consumed earlier.

```text
they type
    → pulse count bumps
    → command-check / confirm / fuzzy command?
         yes → that organ (HELP, SETUP AI, TASK, EXIT, …)
         no  → pending wizard / hub / overlay?
              yes → that walk
              no  → named command match?
                   yes → dispatch that command
                   no  → consume_pending_or_chat
                         (leave, defined words, where-are-we, task actions,
                          stay-with / talk-through, sit, work-block, split,
                          greetings, then free chat)
```

**Stay-with is not free chat.** If a stay or talk-through hold is open, the line is eaten there. The footer still says “Just type to talk or chat.” That invite means: you do not have to pick a digit; ordinary English shelves the numbered list. It does **not** mean the model is now having an open conversation about the house.

If nothing above matches and Hybrid is connected, **free chat** is the one default AI body (`C-03`). That path is idle companion chat, not the bathroom gather ladder.

**Compare:**

- **Holds:** Command vs pending vs stay vs free-chat order. Talk shelves chrome. Writes wait.
- **Drifts:** Footer promises converse (`C-06`); leftover reprint can make the next pulse unchanged (`C-04` every sentence must earn the next pulse; `O-03` just-type as homework). See §12.

## 3. Outer pipeline (granular)

**Law that applies:** **C-05** · **C-08** · **C-12** · **C-04** (where-are-we is ledger recap)

Product entry: `main.py` → `handle_line`.

1. Empty line → local empty-turn card. No pulse bump for some empty cases; a non-empty strip bumps the pulse.
2. **Command check** (`packages/support/command_check.py`). Ambiguous or dangerous commands may confirm. A confirmed command dispatches. Some unknown lines are offered as chat with a note.
3. **Pending walks** win: HELP guide, Atlas chooser, SETUP AI flow, timezone, defined-word, project title, autonomy, task describe, and similar session keys. Digits belong to the printed list while that list is live.
4. **EXIT** is special-cased, then **router** (`surface/router.py`) matches a typed command from the catalog (~300 commands).
5. No command: **fuzzy offer**, else `consume_pending_or_chat` (`surface/handlers.py`).
6. Inside that function, order is long and DET-first. The stay-talk bite that matters for this study:

   - where-are-we (ledger recap, numbered rows)
   - task actions hold
   - **`stay_with.try_consume`** — look-at stay offer, sit-through, work-block / talk-through
   - if a stay-with take was named: **`engage.maybe_paint_stay_take`** (Hybrid after)
   - sit / work-block / split *asks* if no hold yet
   - later: greetings local, then `_chat_via_adapter`

7. The people screen is wrapped with the banner (`kernel/banner.py`): pulse number, DET/AI/NET, quiet help on/off.

**Digits:** live only while `picks_live` on that hold. After talk shelves chrome, a bare `2` is stale until SHOW MENU.

**HELP** is always available. Lowercase/ambiguous command words in free chat may get a just-checking confirm; typed capitals as shown fire.

**Compare:** Holds for banner, digits, HELP, where-are-we as ledger recap (not invented chat progress). SETUP AI quiet-help door is `C-05` / `O-07` (nested, off by default, needs a live path).

## 6. How a stay opens (the bathroom path)

**Law that applies:** **C-04** · **O-02** · **O-04** · **O-03** · **C-12**

Locks:

- Their numbered pick: **I'll take the next line**. Spoken stay-talk never says “the line.”
- Find-block: **Find what is in the way of {title}**. After they pick it, **start the find**.
- Opening find-block includes a **consume-ask** that names the kind of thing. No lens. No JUMP. No reach. No something / this work as the object.
- Outstanding children: one in-hand (named, else gather/supplies/tools title, else first open). Do not change gather-prefer as the first pick.
- First talk-through: no lens (gather-prefer). That lock is the **opening card**, not “never lens on the next okay.”
- Let's complete this task is the stay-with door. After that pick, say the stay once, pin FOCUS.

Typical Try:

1. Look at the focused parent (where-are-we digit, or look-at).
2. Stay offer: Name smaller tasks / Daniel continues / **I'll take the next line** / Let's complete this task / Pause / task actions.
3. **Let's complete this task** pins FOCUS and offers sit-through: Mark complete / **Find what is in the way of this task** / split / pause.
4. Find-block pick → `_open_talk_through`:
   - Load smaller titles from the ledger.
   - **Gather-prefer:** first title whose wording contains `gather`, `supplies`, or `tools`; else the first open child; else the parent.
   - Set `working_on` to that title. `eval_stall` = 0. Chrome stale. `awaiting_talk` = true.
   - Speak opening card: `{in-hand} is the next move. What supplies do you already have for {parent}?`
   - Kind = `in_hand`. No lens. No JUMP.

That title scan **is** the “always Gather supplies” behavior. It is not awareness that cleaning needs supplies. It is a string match on rows you already wrote.

Find-block people copy is locked. After the pick he starts the find by opening that card — he does not first ask what the block is.

**Compare:**

- **Holds:** Opening consume-ask, no lens, no JUMP, gather-prefer as first pick, FOCUS pin, start-the-find instead of reprinting find-block as pick 1.
- **Drifts (copy):** **I'll take the next line** is the locked their-ball pick (`C-04`, `O-03`). Spoken stay-talk already must not say “the line.” Designer now reads that pick as foreign (“hold the line”). The lock is live; the Want may have moved. Guide-update if they cut it.
- **Drifts (intent):** Find-block English plus gather-prefer means “discover the block together” is **not** what the lock currently does. Collaborative ball (`C-04` Want: fabric is conversation; lists are for a yes) is the tension with a silent first child. Changing gather-prefer is an `O-02` Do not until Designer marks it.

## 7. Inner loop — talk-through consume

**Law that applies:** **C-12** · **O-05** · **C-04** · **C-06** · **O-04** · **A-03**

Locks that collide on the same line:

- `O-05`: **Whole-line I don't know is stuck**; Ground then outstanding smaller task, or this task. Stuck **steps to the next method**. A sentence that contains don't-know (“I don’t know if we need gloves”) stays on that piece. Celebrity phrase lists as the only law: Do not. Phrase seed plus shape.
- `C-04`: **Last-take kind interprets eval and stuck. Same words, different cards.** An answer that fills an open item-ask is not leftover.
- `C-06`: When the last take invited an item or referent name, incoming text that is **not** a command, a live digit, **stuck**, **empty**, or I-have Grounds that referent. So law **carves stuck out** of answer-to-ask.
- `C-12`: Local names the family. Do not grow an unbounded phrase list as the law. Leftover English does not retitle in-hand.
- `A-03`: Local owns EVAL / STUCK / named noun / answer-to-ask. Quiet help must not relabel okay as ask-last or steal a bare noun that fills an item-ask.

Once `pending_work_block.awaiting_talk` is true, almost every non-command line hits `_consume_talk_through` (`domains/tasks/stay_with.py`).

**Order of checks (this is the real classifier).** First match wins. Later matches never run.

1. Blank → reprint talk screen.
2. Feature / defined-word question → word-help card.
3. **Quiet help `advise_before`** (only if switch on **and** a chat path is connected **and** this smells like stay-talk). If slots gate in, `_apply_quiet_slots` may route. Local still speaks. Fail → floor families below.
4. Pause line → pause fork.
5. Split request → split offer.
6. Need-list **ask-which** open → match a listed title or a live digit.
7. Named-fork pick (I-have vs lens second meaning).
8. Parse take of an offered example set → write only if they yes’d write; else set in-hand.
9. Refuse / accept an open listed-lens or sibling lean.
10. Empty sit-with + okay / write-yes → eval keep-ball.
11. Stall ≥ 1 or 2 + write-yes of examples.
12. **Eval or stuck or ideas-ask** → `_eval_keep_ball` (this is where `I don't know` goes, **before** empty, **before** item-answer).
13. **Amend / empty-possession** → `_amend_keep_ball` (`I don't have any`).
14. Pass-the-initiative (`what should i get`, `you pick`) → eval keep-ball.
15. Named possession (`I have a toothbrush`) → ground that object, stay on gather.
16. Defer-look (`I'll see what I have`) → they have the next look.
17. **Item-ask open + looks like item answer** → `_answer_to_ask_keep_ball`. Gated: last take kind is need-list **and** last take text matches `first item to get` / `name what to get` / `let's name what`. A list-door “name it” / “in reach” card does **not** open this gate.
18. Ask-last (`what did you mean`, `huh`, `what`) → reprint or answer the last offer. Never “We are on {their sentence}.”
19. Enough / back to the plan → orient stay offer.
20. Task actions / sit request.
21. Live digit on printed picks.
22. Work-shaped help-me / not-a-project-name → next talk beat or reprint last take if empty sit-with.
23. Match an open ledger row by wording → look-at that row (can steal FOCUS if it is a different parent).
24. Need-list or empty sit-with leftover → **reprint `last_take`**.
25. Else `_piece_from_talk` may retitle in-hand from leftover English (blocked for eval/stuck/empty shapes).
26. Else `_next_talk_beat` — leftover path: often reprints or restates in-hand.

**Implication:** “I don't know” never reaches empty-possession or answer-to-ask, because step 12 consumes it as **stuck**. Same words after a have-ask are not interpreted as “I cannot fill that ask.”

Quiet help, when it runs, is **before** this table. Local vetoes: it must not relabel okay as ask-last; must not steal a bare noun that fills an open item-ask; leftover-not-a-title is treated as a nod into eval keep-ball.

**Compare:**

- **Holds:** Family table exists (`C-12`). Empty is a shape (`O-05`). Ask-last reprints (`C-06`). Quiet help cannot steal answer-to-ask (`A-03`). Need-list ask-which (`O-04`). Named possession and defer-look (`O-04`).
- **Law tension:** After a have-ask, Designer hears `I don't know` and `I don't have any` as the same people move. `O-05` + `C-06` make them different (stuck vs empty). `C-04` last-take kind says same words, different cards — the under-lived lock. Product follows `O-05` whole-line stuck, not `C-04` against the open question.
- **Fails:** Item-ask in product is narrower than `O-04` / `C-04` (“when the last take asked them to name an item”). List-door “name it” asked for a name; toothbrush was leftover. See §12.
- **Drifts:** Phrase seed plus shape (`O-05`) is legal; a closed regex as the *only* consume is the encyclopedia `C-06` / `C-12` forbid growing. Parked: richer shape-classifier.

## 8. Line families — what local actually matches

**Law that applies:** **O-05** · **C-06** · **C-04** · **C-12** · **O-04**

Thin speech is **line families**, not a type of person. Implementation is phrase-seed **plus** shape: mostly whole-line regex. Celebrity phrase lists as the *only* law are forbidden; the product still uses a closed seed set so AI-off can move (`N-03`).

| Family | Typical lines | Next beat | Law |
|--------|---------------|-----------|-----|
| **Eval / nod** | okay, yeah, sure, I like this, I said okay | New beat against **last-take kind** | C-06, O-05, C-04 |
| **Stuck** | whole-line I don't know, idk, dunno, I'm lost, not sure, whatever | Ground; next **method rung**; not a title | O-05, O-04 |
| **Ideas-ask** | ideas, help me think (direct support ask) | **One offer**, not a reprint (`C-04`) | C-04, O-05 |
| **Empty-possession** | I don't have any; none of those; got nothing | Close have-inquiry; need-list. Not JUMP | O-05, O-04, C-06 |
| **Pass-initiative** | what should I get; you pick | He goes first; listed sibling as lens/lean | O-02, O-04, O-05 |
| **Ask-last** | what did you say; what; huh; what example set | Answer or reprint last offer | C-06, O-05 |
| **Named possession** | I have a {noun} (not any/none/nothing) | Ground object; stay on gather; not a write | O-04, C-06 |
| **Defer-look** | I'll see what I have; let me look | They have the next look | O-04 |
| **Answer-to-ask** | bare noun or get/need phrase **while item-ask is open** | Hold referent; get vs have bridge | C-04, C-06, O-04 |
| **Leftover** | anything that matched none of the above | Not a title; reprint last take | O-02, C-06, C-12 |

Stuck **excludes** “I don't know if/whether …” so “I don't know if we need gloves” stays on that piece (`O-05`).

Empty is a **shape**: denial of having + empty or indefinite object, no specific noun. “I don't have bleach” is parked leftover (named-noun), not this family.

Okay of last-take kind (`C-06` / `_climbable_kind`):

- Handle-less / existence / opening `in_hand` → blocked, first method (listed-lens if siblings exist).
- `listed_lens` → accept the lens (`working_on` stays).
- `list_door` → list beat (`We can make that list. If something is already in reach, name it.`).
- Closed kinds do not re-apply gather-prefer.

**JUMP vs LENS** (Designer docs, never people words — `C-04`, `O-04`): JUMP changes `working_on` only after they accept a lean. LENS keeps `working_on`; one listed sibling may frame the beat. First talk-through: no lens.

**Compare:** Family inventory **holds**. List-beat copy **fails** `C-04` name-the-referent / no something-in-reach. Ideas-ask **drifts** if it reprints instead of one offer (Try 609 class). Locate-ask exists in `voice.py` and is closer to `O-04` “ask when uncertain” than in-reach; the stuck ladder often skips it.

## 9. Method ladder (pathing rungs)

**Law that applies:** **O-04** · **C-04** · **O-05** · **A-07**

Locks: when blocked — Ground; **one method** that still is the in-hand task; the next pulse uses their answer; “the task exists” is not help. Method rungs are domain-agnostic: consume-ask → listed-area lens (if siblings exist, **after blocked**) → need-list after empty → list door → their line. **One method** this pulse. Bathroom is the Try scene, not an organ. Pathing never live web. Local help-off does not invent spray / bleach / a bin / basket / box / cup. After they said they have none, do not ask what is already in reach again. After empty, need-list is what to get; ask which if several listed titles.

After stuck (or okay of a climbable opening card), `_eval_keep_ball` picks **one** method.

| Rung | `pathing_rung` | Kind | Local sentence (gather in-hand) | Law |
|------|----------------|------|----------------------------------|-----|
| Opening | 0 | `in_hand` | Gather supplies is the next move. What supplies do you already have for {parent}? | O-04 consume-ask, C-04 no bare existence |
| After blocked, siblings exist | 1 | `listed_lens` | I heard you don't know how to start Gather supplies. A next thought: gather what this bathroom needs for the counters. | O-04 LENS after blocked, O-05 stuck steps method |
| Next shrug | 2 | `list_door` | If you'd like, we can make a list of what to get. | O-04 list door |

## 12. What leftover reprint is

**Law that applies:** **C-06** · **O-02** · **C-04** · **C-12** · **O-04**

Locks: while stay is pinned, leftover English is not a title, does not retitle in-hand, and does not start new intake. An answer that fills an open item-ask is **not** leftover. Every people sentence must earn the next pulse. “I heard you” is only honest if the next sentence is a new beat. Reprinting an unchanged numbered list (or the same ask) after they already answered is disingenuous.

If the line matches no family and no item-ask, stay-talk treats it as leftover English and reprints `last_take`.

That is why **toothbrush** after “name it” looped on 732–733: the card was list-door / in-reach, not a need-list first-item ask, so answer-to-ask did not fire; named possession requires **I have**; leftover reprinted the same card.

**Compare:** Leftover-is-not-a-title **holds** (did not mint a task named toothbrush). Consume-the-answer **fails** against `C-04` / `O-04` for any card that asked them to name an item. Product gate is narrower than the lock.
