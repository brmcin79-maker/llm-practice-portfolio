**How to read Hold / Drift / Fail**

| Word | Meaning |
|------|---------|
| **Holds** | The running program matches the lock |
| **Drifts** | The lock is live, but the product only partly lives it |
| **Fails** | The product contradicts a lock |
| **Law tension** | Two chunks pull different ways; the product picked one |
